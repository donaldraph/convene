How Convene works

  1. Reads both calendars — academic and community — over the next few weeks.
  2. Flags collisions deterministically: two timed events overlapping is a hard conflict; an all-day event sharing a date is a softer same-day warning.
  3. Recommends a time for a new event by having Gemini weigh trade-offs a calendar cannot — buffer before a test, sociable hours, breathing room after class — over slots that code has already proven free.
